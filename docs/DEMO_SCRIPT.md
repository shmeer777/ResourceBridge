# Demo Script

1. Sign in as a provider and create a resource with availability and eligibility rules.
2. Sign in as a seeker and find the resource.
3. Submit a booking request.
4. Return to the provider account and approve the request.
5. Demonstrate that overlapping bookings are rejected.
6. Record check-in and check-out.
7. Submit a condition report.
8. Show the authorised audit history.

Keep a fallback demo account and test data ready once implementation begins. Do not put real credentials in this file.
